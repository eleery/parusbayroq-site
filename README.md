# parusbayroq.uz — исходники сайта

Статический сайт на Astro. Русская версия — `/`, узбекская — `/uz/`.

## Сборка

```bash
npm install
npm run build        # результат в dist/
```

`npm run media` пересобирает картинки и видео из `media-src/` (оригиналы с текущего сайта).
Готовые файлы уже лежат в `public/img`, `public/video`, `public/fonts`, поэтому для обычной сборки он не нужен.

## Где что лежит

- `src/legacy/home.html` — разметка главной, перенесённая со старого сайта.
- `src/i18n/strings.json` — тексты RU/UZ из старого `js/i18n.js`.
- `src/i18n/overrides.mjs` — правки текстов (сроки, размеры, оплата, адрес, новые блоки).
- `src/lib/site.mjs` — контакты, title и description, разметка LocalBusiness.
- `src/pages/` — страницы: главная, `/uz/`, политика конфиденциальности, 404, sitemap.xml.
- `public/js/main.js` — калькулятор и формы (без изменений логики, только переводы).
- Формы отправляют заявки в `/api/telegram.php` — этот файл лежит только на хостинге и в сборку не входит.

## Выкладка на Beget (вручную)

1. В файловом менеджере Beget заархивируйте папку сайта и скачайте архив — это резервная копия.
2. Загрузите содержимое `dist/` в корень сайта с заменой файлов.
   Папку `api/` и старые файлы (`images/`, `js/i18n.js` и т. п.) не удаляйте.
3. Добавьте строки из `htaccess-additions.txt` в существующий `.htaccess`.
4. Проверьте `/` и `/uz/`, отправьте тестовую заявку с обеих страниц — она должна прийти в Telegram.
5. В Search Console и Яндекс Вебмастере отправьте `https://parusbayroq.uz/sitemap.xml` и запросите переобход `/uz/`.

## Тестовая копия для просмотра

```bash
npm run build:preview   # результат в dist-preview/
```

Та же сборка, но закрыта от поисковиков (`noindex` и `robots.txt` с `Disallow: /`), без Метрики и тега Google Ads, с пометкой «Тестовая копия» в углу.
Выкладывается на отдельный поддомен, например `test.parusbayroq.uz`, в его собственную папку — не в корень основного сайта.
Формы на тестовой копии работают, только если рядом скопировать папку `api/` с основного сайта.
